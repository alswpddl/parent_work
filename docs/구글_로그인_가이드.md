# 손님 구글 로그인 켜기

손님 주문서의 **구글로 시작하기** 버튼은 Render에 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` 두 값이 있어야 보여요.
값이 없으면 버튼만 숨고, 카카오 로그인·비회원 주문은 그대로 돼요.

## 1. 구글 클라우드에서 OAuth 클라이언트 만들기

1. https://console.cloud.google.com 접속 → 위쪽 프로젝트 선택 → **새 프로젝트** (이름 예: `gayeom-shop`)
2. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면** (화면에 따라 'Google 인증 플랫폼')
   - 앱 이름: `가염식품`, 사용자 지원 이메일: 내 메일
   - 대상(사용자 유형): **외부**
   - 범위는 기본(이메일·프로필·openid)만 — 따로 추가하지 않아요
3. **클라이언트(사용자 인증 정보) → 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 리디렉션 URI에 한 줄 추가:
     `https://parent-work.onrender.com/api/public/shop/auth/google/callback`
4. 만들어지면 나오는 **클라이언트 ID**와 **클라이언트 보안 비밀**을 복사 (채팅에 붙여넣지 말 것)

## 2. Render에 넣기

Render → parent_work → Environment

| 이름 | 값 |
|---|---|
| `GOOGLE_CLIENT_ID` | 클라이언트 ID (`….apps.googleusercontent.com`) |
| `GOOGLE_CLIENT_SECRET` | 클라이언트 보안 비밀 |

저장하면 서버가 다시 켜지고, 1~2분 뒤 주문서 → 로그인에 구글 버튼이 생겨요.

## 3. 모든 손님이 쓸 수 있게 '게시'

처음엔 **테스트 중** 상태라 테스트 사용자로 넣은 계정만 로그인돼요.
OAuth 동의 화면(대상)에서 **앱 게시(프로덕션으로 푸시)** 를 누르면 누구나 로그인할 수 있어요.

## 문제 해결

- `redirect_uri_mismatch` → 3번 주소가 한 글자라도 다른 경우. 그대로 복사해서 다시 넣기
- `access_denied` / '앱이 테스트 중' → 3번 게시를 안 했거나, 테스트 사용자에 없는 계정
- 버튼이 안 보임 → Render 두 값 확인 후 서버 재시작 기다리기

## 참고: 휴대폰 번호 가입은 닫았어요

본인 확인 없이 아무 번호로나 가입되던 '휴대폰 번호 + 비밀번호' 새 가입은 막았어요 (주문하면서 가입하는 것도).
예전에 그렇게 가입한 손님은 로그인 화면의 '예전에 휴대폰 번호로 가입하셨나요?'에서 그대로 로그인할 수 있어요.
다시 열려면 Render에 `ALLOW_PASSWORD_SIGNUP=true`.
