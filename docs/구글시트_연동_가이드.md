# 구글 시트 연결하기 (브라우저만으로, 약 15분)

주문·거래처·품목을 구글 시트에 저장하도록 서버를 연결해요.
연결하면 서버가 잠들거나 다시 켜져도 데이터가 그대로 남고, 부모님은 시트에서도 주문을 볼 수 있어요.

서버가 시트를 쓰려면 **서비스 계정**(서버 전용 구글 계정)이 필요해요.
이건 구글 계정 주인만 만들 수 있어서 직접 해야 하는 단계예요. 나머지(탭 만들기·제목 줄·기본 설정)는 서버가 알아서 해요.

---

## 1. 시트 두 개 준비

| 시트 | 용도 | 부모님과 공유 |
| --- | --- | --- |
| 공장 주문장 | 주문장·거래처·품목·자재재고·월말정산·_설정 | 예 |
| 공장 시스템 | 카카오 로그인 정보·발송 기록 | **아니오** |

구글 드라이브 → **새로 만들기 → Google 스프레드시트** 로 빈 시트를 두 개 만들어요. 이름은 아무거나 괜찮아요.
시트 주소 `https://docs.google.com/spreadsheets/d/`**`이 부분`**`/edit` 이 시트 ID 예요. (주소 전체를 넣어도 서버가 알아서 ID 만 뽑아요)

## 2. 서비스 계정 만들기 (Google Cloud Console)

1. <https://console.cloud.google.com> — 시트를 만든 구글 계정으로 로그인. 결제 정보는 필요 없어요.
2. 위쪽 **프로젝트 선택 → 새 프로젝트** → 이름 `factory-ops` → **만들기** → 그 프로젝트가 선택돼 있는지 확인
3. 위쪽 검색창 **Google Sheets API** → **사용**
4. 검색창 **서비스 계정** → **서비스 계정 만들기** → 이름 `factory-ops` → **완료** (역할은 비워 둬도 돼요)
5. 목록에서 만든 계정을 눌러 **이메일 주소**(`factory-ops@….iam.gserviceaccount.com`)를 복사
6. **키** 탭 → **키 추가 → 새 키 만들기 → JSON → 만들기** → `.json` 파일이 내려받아져요

> ⚠️ 키 파일 내용은 비밀번호와 같아요. 채팅·카톡·GitHub 에 올리지 말고 Render 에만 넣으세요.
> 여럿이 쓰는 컴퓨터라면 Render 에 넣은 뒤 다운로드 폴더와 휴지통에서 꼭 지우세요.

## 3. 시트를 서비스 계정과 공유

두 시트 각각 오른쪽 위 **공유** → 5번 이메일 붙여넣기 → **편집자** → (알림 보내기 체크 해제) → **공유**

## 4. Render 에 넣기

Render → 내 서비스 → 왼쪽 **Environment** → **Edit** → **Add variable**

| Key | Value |
| --- | --- |
| `SHEETS_BACKEND` | `gspread` |
| `GOOGLE_SPREADSHEET_ID` | 공장 주문장 시트 ID (또는 주소 전체) |
| `SYSTEM_SPREADSHEET_ID` | 공장 시스템 시트 ID (또는 주소 전체) |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | 키 파일을 메모장으로 열어 `{` 부터 `}` 까지 전부 |

저장 버튼 옆 ▼ → **Save, rebuild, and deploy**

## 5. 확인

- Render **Logs** 에 `bootstrap: {'tabs_added_headers': …` 가 보이고 상태가 **Live** 면 성공
- 공장 주문장 시트를 새로고침하면 `주문장 · 거래처 · 품목 · 자재재고 · 월말정산 · _설정 · _기록 …` 탭이 생겨 있어요
- 관리 화면 **기본 정보 → 연결 상태 → 구글 시트 → [연결 확인]** 을 눌러도 확인할 수 있어요

## 안 될 때

Render Logs 마지막 줄에 이유가 한국어로 나와요.

| 로그 내용 | 할 일 |
| --- | --- |
| `GOOGLE_SERVICE_ACCOUNT_JSON 을 읽지 못했어요` | 키 파일 내용을 `{` 부터 `}` 까지 빠짐없이 다시 붙여넣기 |
| `구글 시트(…)를 열지 못했어요` | ① 시트 ID ② 서비스 계정 이메일과 **편집자** 공유 ③ Google Sheets API **사용** — 셋 다 확인 |
| `GOOGLE_SPREADSHEET_ID 가 비어 있습니다` | 4번 표의 값이 빠졌는지 확인 |

## 시트를 쓸 때 주의

- 부모님이 **열 순서를 바꾸거나, 메모 열·수식을 추가해도** 괜찮아요. 서버는 1행 제목으로 열을 찾아요.
- 단, **1행 제목 글자는 바꾸지 마세요.**
- `_설정` 탭의 '값' 칸은 시트에서 직접 고쳐도 돼요 (예: 택배비 `3,000원`).
