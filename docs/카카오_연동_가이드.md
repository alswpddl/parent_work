# 카카오 연동 가이드

이 시스템은 카카오를 **두 가지** 방식으로 씁니다.

| 용도 | 받는 사람 | 방식 | 비용 |
|---|---|---|---|
| 아침 브리핑, 재고 경고, 셀프주문 알림, 월말정산 안내 | 부모님 | 카카오 디벨로퍼스 **'나에게 보내기'** | 무료 |
| 택배·화물 출고 안내, 거래명세표 링크, 주문 접수 안내 | 거래처 담당자 | **솔라피 알림톡** | 건당 과금 |

---

## 1. 부모님 카톡 — '나에게 보내기'

### 1-1. 카카오 디벨로퍼스 앱 만들기 (한 번만)
1. https://developers.kakao.com 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**
2. **앱 키**에서 **REST API 키** 복사 → 서버 환경변수 `KAKAO_REST_API_KEY`
3. **카카오 로그인 → 사용 설정**을 **ON** (꺼져 있으면 KOE004 오류)
4. **카카오 로그인 → 리다이렉트 URI**에 아래 주소 등록 (다르면 KOE006 오류)
   ```
   https://<Render 서버 주소>/api/integrations/kakao/callback
   ```
   앱 화면 [기본 정보·카톡 → 카톡·알림]에도 서버가 기대하는 주소가 그대로 표시돼요.
5. **카카오 로그인 → 동의항목**에서 **카카오톡 메시지 전송(talk_message)** 을 '선택 동의'로 설정
6. **보안 → Client Secret** 이 켜져 있으면 코드를 복사 → `KAKAO_CLIENT_SECRET`
7. **제품 링크 관리 → 웹 도메인**에 프론트 주소(예: `https://factory-ops.vercel.app`) 등록
   → 카톡 메시지의 [열어보기] 버튼이 이 주소로 연결돼요. 등록하지 않으면 버튼이 안 보일 수 있어요.

### 1-2. 연결하기 (부모님 휴대폰에서)
1. 부모님 휴대폰으로 앱 접속 → **기본 정보·카톡 → 카톡·알림 → [카카오 연결]**
2. 카카오 화면에서 **카카오톡 메시지 전송**에 동의
3. 앱으로 돌아오면 "연결됐어요" 표시 + 부모님 카톡 **나와의 채팅**에 확인 메시지 도착
4. **[테스트 보내기]** 로 한 번 더 확인

### 1-3. 알아둘 점
- 카톡 텍스트 메시지는 200자 제한이 있어서, 긴 브리핑은 서버가 줄 단위로 나눠 여러 개로 보내요.
- 연결 토큰은 약 2개월 유효하고, `jobs-cron.yml` 이 매주 월요일 자동 갱신해요. 갱신이 실패하면(예: 부모님이 카카오 설정에서 연결을 끊음) 앱 홈에 '카카오 연결' 경고가 떠요 → 다시 연결.
- 받을 수 있는 사람은 **연결한 카카오 계정 한 명**뿐이에요(나에게 보내기). 두 분 다 받으려면 단톡방에 전달하거나, 비즈니스 인증 후 '친구에게 보내기'로 확장해야 해요.
- 토큰은 `SYSTEM_SPREADSHEET_ID` 시트(없으면 본 시트의 `_토큰` 탭)에 저장돼요. 이 탭은 지우지 마세요.

## 2. 거래처 알림톡 — 솔라피

### 2-1. 준비물 (처음 한 번, 승인까지 며칠 걸림)
1. https://solapi.com 가입 → 충전
2. **발신번호 등록** (공장 전화번호) → `SOLAPI_SENDER` — 알림톡 실패 시 문자로 대신 보낼 때 씀
3. **카카오톡 채널** 만들기 (https://center-pf.kakao.com) → 비즈니스 인증
4. 솔라피 콘솔 **카카오 채널 연동** → 발급된 채널 ID(pfId) → `SOLAPI_PFID`
5. 솔라피 콘솔 **알림톡 템플릿 등록** — `docs/알림톡_템플릿.md` 문구를 그대로 복사해 4개 등록
   (앱 화면 [카톡·알림 → 템플릿 문구 보기]에서도 복사 가능)
6. 승인되면 템플릿 ID 를 환경변수에:
   `SOLAPI_TPL_PARCEL` / `SOLAPI_TPL_TRUCK` / `SOLAPI_TPL_STATEMENT` / `SOLAPI_TPL_ORDER_RECEIVED`
7. **API Key 관리**에서 키 발급 → `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`

### 2-2. 언제 보내지나
- **택배**: 송장번호가 들어가는 순간 (송장 엑셀 올리기 / 송장 직접 입력)
- **화물**: 차량번호를 넣고 출고할 때
- **주문 접수**: 거래처가 셀프주문 링크로 주문했을 때 (`SOLAPI_TPL_ORDER_RECEIVED` 가 있을 때만)
- **명세서**: 월말 정산 화면에서 [보내기]
- 같은 주문에 두 번 보내지 않아요. 다시 보내려면 주문 상세 → [알림톡 다시 보내기].
- 거래처 정보에서 '출고 알림톡 받기'를 끄면 그 거래처는 빠져요. 휴대폰 번호(010…)가 아니면 보내지 않아요.
- 결과는 시스템 시트 `발송기록`(또는 `_발송기록`) 탭과 앱 [카톡·알림 → 최근 발송 기록]에서 확인.

### 2-3. 템플릿을 고치고 싶을 때
문구는 바꿔도 되지만 `#{거래처명}` 같은 **변수 이름은 그대로** 두세요. 변수를 추가하려면
`backend/app/modules/q3_notify/templates.py` 와 `service.py` 의 변수 채우는 부분을 같이 고쳐야 해요.

## 손님 '카카오로 시작하기' (웹 주문서 로그인)

부모님 알림용으로 만든 같은 카카오 앱을 그대로 써요. 추가로 할 일은 하나예요.

1. 카카오 개발자 사이트 → 내 애플리케이션 → 앱 → **[앱] → [플랫폼 키] → REST API 키** → 리다이렉트 URI에 아래 주소를 **하나 더** 추가
   - `https://parent-work.onrender.com/api/public/shop/auth/kakao/callback`
2. 끝. 주문서 마이페이지에 노란 **카카오로 시작하기** 버튼이 생겨요.

- 처음 온 손님은 성함·휴대폰 번호만 한 번 적으면 가입돼요.
- 같은 번호로 비밀번호 가입한 손님은 그 비밀번호를 한 번 넣으면 카카오와 연결돼요 (남의 계정 가로채기 방지).
- 시트 '거래처' 탭 **카카오ID** 칸을 지우면 연결이 끊겨요.
