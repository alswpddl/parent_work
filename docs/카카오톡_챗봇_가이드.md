# 카카오톡 채널 챗봇 연결하기 (브라우저만으로, 약 20분)

손님이 공장 **카카오톡 채널**에 말을 걸면 우리 서버가 바로 답해요.

| 손님이 보내면 | 챗봇 답 |
| --- | --- |
| 채팅방 처음 열기 / 안녕하세요 / 메뉴 | 인사 + **세로 메뉴** (상품·가격 · 주문하기 · 택배비 · 받는 날 · 입금 계좌) + [전화하기] [주문서 열기] |
| 상품·가격 / 얼마예요 | 지금 파는 젓갈과 가격 + [주문서 열기] |
| 명란 있어요? / 액젓 얼마 | 그 상품만 안내 + [이 상품 주문] (품목의 '별칭'도 알아들어요) |
| 주문하기 | 웹 주문서 링크 + [전화하기] |
| 택배비 | 택배비 · 무료배송 기준 · 화물 기준 |
| 언제 받아요? | 가장 빠른 받는 날 · 쉬는 요일 |
| 입금 계좌 | 계좌 안내 |
| 전화 | [전화하기] 버튼 |
| 그 밖의 글 | "글로 답해 드리지 않아요, 메뉴에서 골라 주세요" + 세로 메뉴 (1:1 상담으로 안 넘어감) |

- 답 아래에는 **[메뉴 보기]** 버튼 하나만 붙어요 (옆으로 길게 밀리던 버튼 줄 없음).
- 주문 조회는 챗봇에서 하지 않아요. 손님은 주문서 **마이페이지**나 **주문 조회** 화면에서 봐요.
- 손님이 직접 쓴 글은 구글 시트 `_기록` 탭에 **챗봇 질문**으로 남아요. 자주 나오는 질문은 품목 '설명'이나 공지에 넣으면 돼요.

> 정해진 질문에만 정해진 답을 해요 (AI 없음, 추가 요금 없음). 카카오는 **5초 안에** 답해야 하는데, 정해진 답이라 바로 나가요.
> 무료 서버가 잠들어 있으면 첫 질문에 답을 못 할 수 있어요 → 저장소 자동 깨우기(`API_BASE_URL` 변수)를 켜 두세요.

## 1. 카카오톡 채널 만들기 (이미 있으면 건너뛰기)

1. <https://business.kakao.com> → 부모님(또는 공장) 카카오 계정으로 로그인
2. **채널 만들기** → 채널 이름(예: 예시젓갈), 검색용 아이디, 프로필 사진
3. 채널을 **공개**로, 검색 허용으로 두면 손님이 카톡에서 찾을 수 있어요

## 2. 챗봇 만들기 (카카오 챗봇 관리자센터)

1. <https://chatbot.kakao.com> → 같은 계정으로 로그인 → **봇 만들기** → 카카오톡 챗봇
2. 봇 이름: 예) `예시젓갈 상담`

## 3. 스킬 등록 (우리 서버 주소)

1. 관리 화면 **기본 정보 → 연결 상태 → 💬 카카오톡 채널 챗봇** 의 **스킬 주소**를 복사
   (`https://…onrender.com/api/kakao/skill?key=…` — 비밀 키가 들어 있으니 남에게 보여 주지 마세요)
2. 챗봇 관리자센터 왼쪽 **스킬** → **생성**
   - 스킬명: `공장 서버`
   - URL: 복사한 스킬 주소
3. 아래 **스킬 테스트** → **스킬 서버로 전송** → 응답 미리보기에 답이 나오면 성공

## 4. 블록에 스킬 연결

**폴백 블록**(못 알아들은 말이 가는 곳)과 **웰컴 블록**(처음 들어왔을 때) 두 곳에 똑같이 해요.

1. 왼쪽 **시나리오** → 기본 시나리오 → **폴백 블록**
2. 파라미터 설정의 **스킬** 에서 `공장 서버` 선택
3. 봇 응답에서 **스킬데이터 사용** 선택 → **저장**
4. **웰컴 블록** 도 같은 방법으로

이렇게 하면 손님이 무슨 말을 하든 우리 서버가 답해요. (블록을 따로 만들 필요 없어요)

## 5. 배포하고 채널 연결

1. 왼쪽 **배포** → **배포** 버튼
2. **설정** → 카카오톡 채널 연결 → 1번 채널 선택 → 저장
3. 휴대폰 카카오톡에서 채널을 친구 추가하고 "택배비" 라고 보내 보세요

> 화면 이름은 카카오가 바꿀 수 있어서 조금 다를 수 있어요. 막히면 화면 글자를 보내 주세요.

## 손님에게 알리기

- 주문서·명함·제품 라벨에 "카카오톡에서 **예시젓갈** 검색" 문구
- 카카오톡 채널 홈에 **웹 주문서 주소** 링크 추가 (채널 관리자센터 → 프로필 → 버튼)
