# 네이버 · 애플 로그인 켜기

키를 Render → Environment 에 넣으면 손님 로그인 화면에 버튼이 저절로 생겨요. (키는 채팅·깃허브에 붙여 넣지 마세요)

## 네이버 (무료)
1. developers.naver.com → Application → 애플리케이션 등록
2. 사용 API: **네이버 로그인** / 제공 정보: **이름**(필수)
3. 환경: PC 웹 · 모바일 웹
   - 서비스 URL: `https://gayeom.vercel.app`
   - Callback URL: `https://parent-work.onrender.com/api/public/shop/auth/naver/callback`
4. Render 에 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`
5. 처음엔 '개발 중' 상태라 등록한 아이디만 로그인돼요 → 검수 요청을 하면 모두 쓸 수 있어요.

## 애플 (애플 개발자 프로그램 연 129,000원 필요)
1. developer.apple.com → Certificates, Identifiers & Profiles
2. Identifiers → **App ID** 하나 만들고 *Sign in with Apple* 체크
3. Identifiers → **Services IDs** 만들기 (예: `kr.gayeom.login`) → Sign in with Apple 켜고 Configure
   - Domains: `parent-work.onrender.com`
   - Return URLs: `https://parent-work.onrender.com/api/public/shop/auth/apple/callback`
4. Keys → 새 키, *Sign in with Apple* 체크 → **.p8 파일 내려받기** (한 번만 받을 수 있어요)
5. Render 에 넣기
   - `APPLE_CLIENT_ID`: 3번 Services ID
   - `APPLE_TEAM_ID`: 오른쪽 위 Team ID (10자리)
   - `APPLE_KEY_ID`: 4번 키 ID (10자리)
   - `APPLE_PRIVATE_KEY`: .p8 파일 내용 전체 (BEGIN 줄부터 END 줄까지)
