# 알림톡 템플릿 원문

솔라피 콘솔 → 알림톡 템플릿 등록에 아래 문구를 **그대로** 붙여넣고 심사를 받으세요.
승인되면 템플릿 ID 를 표의 환경변수에 넣습니다. `#{...}` 는 서버가 채우는 변수예요.

> 이 문서는 `backend/app/modules/q3_notify/templates.py` 에서 만들었어요. 문구를 바꾸면 두 곳을 같이 고쳐 주세요.

## 택배 출고 안내  (`SOLAPI_TPL_PARCEL`)

```
[#{공장명}] 택배 출고 안내

#{거래처명}님, 주문하신 물품이 택배로 출고되었습니다.

■ 주문번호: #{주문번호}
■ 품목: #{품목}
■ 택배사: #{택배사}
■ 송장번호: #{송장번호}

배송 조회: #{조회링크}
문의: #{공장전화}
```

## 화물 출고 안내  (`SOLAPI_TPL_TRUCK`)

```
[#{공장명}] 화물 출고 안내

#{거래처명}님, 주문하신 물품이 화물차로 출발했습니다.

■ 주문번호: #{주문번호}
■ 품목: #{품목}
■ 총 중량: #{중량}
■ 차량번호: #{차량번호}
■ 기사님 연락처: #{기사연락처}
■ 도착 예정: #{도착예정}

문의: #{공장전화}
```

## 거래명세표 안내  (`SOLAPI_TPL_STATEMENT`)

```
[#{공장명}] #{정산월} 거래명세표

#{거래처명}님, #{정산월} 거래명세표를 보내드립니다.

■ 납품 건수: #{건수}건
■ 합계 금액: #{합계}원

명세표 보기: #{링크}
#{입금안내}
```

## 주문 접수 안내  (`SOLAPI_TPL_ORDER_RECEIVED`)

```
[#{공장명}] 주문 접수 안내

#{거래처명}님, 주문이 접수되었습니다.

■ 주문번호: #{주문번호}
■ 품목: #{품목}
■ 받는 날: #{납기}

변경이 필요하시면 #{공장전화}로 연락 주세요.
```
