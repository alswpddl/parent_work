# 온라인 결제 (토스페이먼츠)

손님이 주문 완료 화면·마이페이지·주문 조회에서 **[카드·간편결제로 결제하기]**를 누르면
토스페이먼츠 결제창이 열리고, 결제가 끝나면 주문장에 **입금확인·결제수단·결제키**가 자동으로 들어갑니다.

- 카드 번호·CVC·계좌 같은 결제 정보는 **토스 결제창에서만** 입력돼요. 우리 서버·구글 시트에는 남지 않아요.
- 금액은 서버가 주문장에서 계산하고, 승인할 때 한 번 더 맞춰 봐요 (주소창 금액을 바꿔도 결제 안 됨).
- 카드 결제한 주문을 관리 화면에서 **취소하면 자동 환불**돼요. 환불이 실패하면 취소도 안 되고 이유를 보여 줘요.
- 계좌 입금도 그대로 받을 수 있어요 (둘 중 손님이 고름).

## 켜는 법

1. tosspayments.com 가입 → 상점관리자 왼쪽 아래 **개발자센터** → **API 키**
2. **결제위젯 연동 키**의 클라이언트 키(`test_gck_…`)와 시크릿 키(`test_gsk_…`)를 복사
3. Render → parent_work → Environment 에
   - `TOSS_CLIENT_KEY` = 클라이언트 키
   - `TOSS_SECRET_KEY` = 시크릿 키 (절대 채팅·코드에 붙여넣지 말 것)
4. 관리 화면 **설정 → 연결 상태 → 온라인 결제** 카드가 '테스트 모드'로 바뀌면 끝

테스트 키로는 진짜 카드를 넣어도 돈이 빠지지 않아요.

## 실제 결제 받기 (라이브)

토스페이먼츠와 **계약·심사**가 끝나야 라이브 키(`live_gck_…`, `live_gsk_…`)가 나와요.
사업자등록증, 통신판매업 신고, 정산받을 계좌 등이 필요해요 (정확한 서류·수수료는 토스페이먼츠 안내 확인).
라이브 키로 Render 값만 바꾸면 코드 수정 없이 실제 결제가 돼요.
