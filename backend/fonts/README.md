# 거래명세표 PDF 한글 폰트

`NotoSansKR-Regular.ttf` 는 **Noto Sans CJK KR Regular** 에서 한글 음절(가–힣)·호환 자모·영문·숫자·기본 기호만
남기고, ReportLab 이 읽을 수 있도록 윤곽선을 TrueType 형식으로 바꾼 파일입니다 (약 2MB).

- 원본: https://github.com/notofonts/noto-cjk
- 라이선스: SIL Open Font License 1.1 (`OFL.txt`) — 상업적 사용·재배포 가능, 폰트 파일 단독 판매 금지

다른 폰트(예: 나눔고딕)를 쓰고 싶으면 TTF 파일을 이 폴더에 두고 환경변수 `PDF_FONT_PATH=fonts/파일이름.ttf` 를 지정하세요.
